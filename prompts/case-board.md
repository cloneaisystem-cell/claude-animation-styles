# /case-board — cork, pins, red string

Animate a detective's cork board solving "who ate the last slice?". Use real cork texture, warm desk-lamp light and a slight 3D tilt. In the middle is a polaroid of an empty pizza box labelled EXHIBIT A. Polaroids of four suspects (the roommate, the cat, the dog, the neighbour) slam onto the board with push pins. Add typed index cards with times, sticky notes in marker and a blank "VERDICT:" card. Red string snaps from pin to pin, linking the pizza box to each suspect. Then cut closer and push the camera in. The last string pulls tight to the dog. A red marker circles the dog's face in one rough loop and writes "GUILTY" on the verdict card pinned underneath. Then push in on the dog: there is tomato sauce on its nose, and it licks it off.
